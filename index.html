This page needs to be served, not opened as a file.

index.html in the project root is the development entry point. It loads the app from /src/main.tsx, which only exists while a server is running, so double-clicking it shows nothing.

Run one of these from the project folder:

npm install
npm run dev            → http://localhost:5173
npm run build
npm run preview        → http://localhost:4173

npm run preview serves the real production build — the same files a host serves. Note that browsers also block ES modules over file://, so opening dist/index.html directly may fail for the same reason.
